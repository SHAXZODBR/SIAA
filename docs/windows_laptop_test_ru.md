# Ноутбук с Windows — чек-лист офлайн-теста (для основателя)

Цель: собрать установщик **на своём ноутбуке с Windows**, установить его, **выключить Wi-Fi** и убедиться,
что весь продукт работает без интернета: вход → мастер настройки → реальная МРТ головного мозга → 2 находки →
отчёт на русском → подпись → PDF → переключение языка → перезапуск с восстановленным исследованием.
Английская версия — `windows_laptop_test_en.md`. Распечатайте страницу и отмечайте пункты по ходу.

## 0. Что нужно

| | Требование | Зачем |
|---|---|---|
| ☐ | Windows 10 или 11, **64-бит (x64)**, не ARM | PyInstaller и CPU-сборка PyTorch есть только под x64 |
| ☐ | **16 ГБ ОЗУ** | заморозка бэкенда и загрузка ViT-моделей |
| ☐ | **15 ГБ свободно** на диске, где будет `C:\SIAA` | venv 3 ГБ + PyInstaller 4 ГБ + node_modules 1 ГБ + установщик 4 ГБ |
| ☐ | **Python 3.11 (64-бит)** — ставится один раз, с интернетом | `winget install --id Python.Python.3.11 -e --source winget` или python.org → *Windows installer (64-bit)*, галочка *Add python.exe to PATH* |
| ☐ | **Node.js 20 LTS** (20.19+; 22.12+ тоже подходит, **24 — нет**) | `winget install --id OpenJS.NodeJS.LTS -e --source winget` или nodejs.org → `node-v20.x.x-x64.msi` |
| ☐ | Интернет **только на время сборки** (pip, npm, инструменты electron-builder) | модели уже лежат в комплекте — ничего, связанного с моделями, не скачивается |
| ☐ | Папка комплекта `SIAA_Windows_Kit` (≈ 2 ГБ: `sentinel\`, `demo_study\`, `models\`, `README_FIRST.txt`) | собирается на Mac скриптом `packaging/make_windows_kit.sh` |

Скрипт сборки сам всё это проверяет и при нехватке печатает точную команду установки.

## 1. Сборка (интернет ВКЛЮЧЁН, ~45–90 мин)

1. ☐ Скопируйте весь комплект на ноутбук как **`C:\SIAA`** → должен существовать файл `C:\SIAA\sentinel\packaging\build_windows.ps1`.
2. ☐ Откройте PowerShell в папке `C:\SIAA\sentinel` (Проводник → Shift + правый клик по пустому месту → *Открыть окно PowerShell здесь*).
3. ☐ Выполните
   ```powershell
   powershell -ExecutionPolicy Bypass -File packaging\build_windows.ps1
   ```
   Шаги 0–7 печатаются на экран и пишутся в `packaging\build_windows.log`. Последний шаг (сжатие установщика) 10–20 минут выглядит как зависание — это нормально.
4. ☐ В конце — `BUILD OK`, путь и размер установщика: `C:\SIAA\sentinel\desktop-app\release\Sentinel Medical AI Setup 1.0.0.exe` (ожидается ≈ 1,5–2 ГБ).
   Повторный запуск скрипта безопасен: готовые шаги пропускаются.
5. ☐ Если ошибка: скрипт печатает имя шага, последние 40 строк журнала и **`>>> Send this file to the developer: C:\SIAA\sentinel\packaging\build_windows.log`** — отправьте этот файл. Две известные заминки: *Cannot create symbolic link* на этапе electron-builder → Параметры Windows → *Для разработчиков* → **Режим разработчика ВКЛ**, запустить снова; ошибки *node-gyp / MSBuild* → у вас Node 24, поставьте Node 20 LTS.

## 2. Установка (интернет пока может оставаться)

6. ☐ Двойной клик по `.exe`. SmartScreen: *Система Windows защитила ваш компьютер* (сборка не подписана сертификатом) → **Подробнее** → **Выполнить в любом случае**.
7. ☐ Установщик показывает предупреждение RU/EN → ОК; папку по умолчанию не менять; завершить. На рабочем столе появится ярлык *Sentinel Medical AI*.

## 3. Уходим в офлайн

8. ☐ **Выключите Wi-Fi** (и отключите кабель). Значок сети должен показывать «нет подключения». Всё, что ниже, должно работать в этом состоянии.

## 4. Первый запуск, вход, смена пароля

9. ☐ Запустите *Sentinel Medical AI*. В первый раз ждите до 2–3 минут (Defender один раз проверяет бэкенд). На экране входа сервер ИИ должен быть доступен (нет красной полосы *Сервер ИИ не запущен*).
10. ☐ Найдите **одноразовый пароль администратора**. Переменная `SENTINEL_ADMIN_PASSWORD` приложением не задаётся, поэтому сервер сгенерировал пароль и напечатал его один раз. Откройте в Блокноте:
    `%APPDATA%\sentinel-medical-ai\logs\backend.log`  (= `C:\Users\<вы>\AppData\Roaming\sentinel-medical-ai\logs\backend.log` — путь `%APPDATA%\…` можно вставить прямо в адресную строку Проводника)
    и найдите строку `FIRST-RUN ADMIN ACCOUNT CREATED`. Строка `password: …` — это он. Тот же баннер есть и в `%APPDATA%\sentinel-medical-ai\logs\sentinel_ГГГГ-ММ-ДД.log`.
    Внимание: установщик заодно создаёт пустую папку `%APPDATA%\Sentinel Medical AI\` — её игнорируйте; настоящая папка данных — строчная, через дефис: `sentinel-medical-ai`.
11. ☐ Войдите как **`admin`** с этим паролем.
12. ☐ Сразу появится экран **Смена пароля** (временный пароль нужно заменить). Задайте новый (≥ 8 символов — более короткий приложение не примет) → попадаете в мастер настройки.

## 5. Мастер настройки (5 шагов)

13. ☐ **Язык** → русский (по умолчанию) → Далее.
14. ☐ **Клиника** → любое название → Далее.
15. ☐ **Сервер ИИ** → нажмите **Проверить соединение**. В карточке *Состояние сервера* должно быть **Соединение установлено**, а в списке *Загруженные модели* — **`brain_triage` — Загружена** (обязательное условие). `brain_tumor_class` и `chest` обычно тоже *Загружена* (обе прогреваются при старте). → Далее.
16. ☐ **Лицензия** → **Пропустить** (для теста достаточно демо-режима).
17. ☐ **Поддержка** → Завершить настройку. Появится пустой список исследований; в статусе сервера не должно быть слова *degraded*.

## 6. Реальное исследование

18. ☐ В списке исследований нажмите **Папка** и выберите **`C:\SIAA\demo_study`** (папку целиком; внутри 23 DICOM-файла в подпапках серий). Загрузка + анализ на CPU — 20–90 с.
19. ☐ Исследование появилось в списке; в центральном окне — **настоящий срез МРТ головного мозга** (не заглушка-узор).
20. ☐ Вкладка **Находки**: ожидаются **2 находки**:
    - **Отклонение (триаж)** — статус **Валидировано** (узбекская триаж-модель; по заключению рентгенолога в этом исследовании опухоль, поэтому флаг ожидаем),
    - класс опухоли, например **Глиома** — статус **Валидация не завершена** (публичный классификатор опухолей, локально не валидирован).
    Итоговая строка — *ИИ отметил находку — требуется просмотр*, под ней дисклеймер на русском.
21. ☐ Вкладка **Отчёт**: текст отчёта на русском (шаблонные разделы: показание / методика / описание / заключение).
22. ☐ Нажмите **Подписать отчёт** → подтвердите. Появится строка *Подписал: Administrator · <дата/время>*, текст станет только для чтения.
23. ☐ Нажмите **Экспорт подписанного PDF** → выберите папку → PDF сохранён, Проводник открывается на файле. **Откройте PDF**: кириллица читается (не квадратики), есть название клиники, находка, строка подписи и идентификатор модели `0d559766ce58`.

## 7. Языки

24. ☐ Переключатель языка справа вверху → **UZ**: весь интерфейс на узбекском (латиница); во вкладке Отчёт доступен узбекский отчёт.
25. ☐ Переключите на **EN**: интерфейс на английском. Верните **RU**.

## 8. Перезапуск

26. ☐ Полностью закройте приложение (крестик окна; на Windows бэкенд останавливается вместе с ним). Откройте снова, войдите.
27. ☐ Исследование **осталось в списке** и после выбора показывает **то же изображение мозга**, те же находки и отчёт (восстановлено из локальной базы + `%APPDATA%\sentinel-medical-ai\previews`).
28. ☐ Всё это время были офлайн? Тест пройден. Включайте Wi-Fi.

## 9. Если видите X → пришлите мне Y

| Вы видите | Пришлите |
|---|---|
| `build_windows.ps1` остановился с `BUILD FAILED at step …` | `C:\SIAA\sentinel\packaging\build_windows.log` |
| В SmartScreen нет *Выполнить в любом случае* (только *Не выполнять*) | скриншот; правый клик по .exe → Свойства → галочка *Разблокировать* → Применить и повторить |
| На экране входа красная полоса *Сервер ИИ не запущен* дольше 5 минут | `%APPDATA%\sentinel-medical-ai\logs\backend.log` + самый свежий `sentinel_*.log` из той же папки |
| Окно *Перезапуск сервера ИИ / Сервер ИИ остановлен* | те же два журнала + скриншот окна |
| В журналах нет баннера `FIRST-RUN ADMIN ACCOUNT CREATED` | оба журнала; и скажите, есть ли файл `%APPDATA%\sentinel-medical-ai\sentinel.db` (в старой базе от прошлого теста админ уже создан — удалите всю папку `sentinel-medical-ai` и запустите заново) |
| Проверка соединения → *degraded* / `brain_triage — Не загружена` | backend.log + скриншот карточки *Состояние сервера*; текст причины рядом с моделью |
| Загрузка папки → *В выбранных файлах нет DICOM (.dcm)* или всплывающая ошибка | скриншот уведомления + какую папку выбирали |
| Исследование проанализировано, но в окне серая заглушка / нет изображения | скриншот + backend.log |
| Находок меньше или больше двух, либо триаж не сработал | скриншот вкладки Находки (со статусами) + backend.log |
| В PDF вместо кириллицы □□□ или *Не удалось экспортировать PDF* | сам PDF + скриншот |
| После перезапуска исследование пропало или без изображения | backend.log + вывод команды `dir %APPDATA%\sentinel-medical-ai\previews` |
| Windows Defender / антивирус помещает `sentinel-backend.exe` или установщик в карантин (ложное срабатывание на PyInstaller) | скриншот предупреждения; затем Безопасность Windows → Защита от вирусов и угроз → Исключения → добавить `C:\SIAA` и папку установки, запустить снова |
| Что-то другое | скриншот + точный текст ошибки + backend.log |

В журналах нет имён и идентификаторов пациентов (обезличиваются при записи) — их можно отправлять.
