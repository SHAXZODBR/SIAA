# SIAA — Sentinel Medical AI · Заявление о назначении

Версия 1.0.0 · Редакция документа 2026-09

## Назначение

Sentinel Medical AI — **локально установленное программное обеспечение поддержки принятия решений**, которое анализирует МРТ-исследования головного мозга и (а) отмечает исследования с возможной патологией, чтобы их можно было **приоритизировать для просмотра врачом-рентгенологом**, и (б) готовит черновик структурированного заключения на русском, узбекском или английском языке для редактирования и подписания врачом. Это средство триажа. Оно не ставит диагноз, не локализует изменения и не объявляет ни одно исследование нормальным.

## Пользователи

Врачи-рентгенологи и врачи клиники, в которой установлена программа, действующие в рамках клинических регламентов клиники; ИТ-персонал клиники — для установки и администрирования. Не предназначено для пациентов и немедицинских пользователей.

## Показания

- **МРТ головного мозга** (стандартные протоколы у взрослых; аксиальные серии T1, T1 с контрастом, T2 и/или FLAIR): приоритизация исследований для описания. Это единственное валидированное показание.
- **КТ головы**: программа может направить КТ головы к публичному классификатору внутричерепных кровоизлияний, если эта модель установлена; её вывод помечается как *валидация не завершена*, и **никаких заявлений о точности для КТ не делается**. Если модель не установлена, исследование возвращается с пометкой «требуется просмотр» без вывода ИИ.
- Другие модальности и области тела не входят в назначение; такие исследования возвращаются с пометкой «требуется просмотр».

## Противопоказания и ограничения

- **Не для самостоятельной диагностики, скрининга или исключения заболевания.** Исследование без флага ИИ *не* прочитано как норма: в локальной валидации примерно 1 из 10 патологических исследований не отмечалось.
- **Не «сертификат нормы».** Панель детекторов распознаёт только перечисленные типы находок; любая другая патология для неё невидима.
- **Классификатор опухолей мозга** (глиома / менингиома / гипофиз) — публичная модель с *незавершённой* валидацией на локальной популяции, дающая избыточные срабатывания. Его флаги — и его вывод «опухоль не выявлена» — нельзя использовать клинически без собственного описания врача.
- Детекторы ишемического инсульта и атрофии мозга *экспериментальные* и при анализе целого исследования не запускаются. Выявление кровоизлияний, поражения белого вещества и гидроцефалии не реализовано.
- Точность **не** установлена для: детей, оперированного или пролеченного мозга, нестандартных и неаксиальных протоколов, исследований с выраженными двигательными или металлическими артефактами, моделей томографов, отсутствующих в локальных обучающих данных, а также DICOM-экспорта с неполными заголовками.
- Не предназначено для решений, критичных по времени (например, исключение острого инсульта или кровоизлияния).
- Черновики заключений, переводы и ответы «Спросить ИИ» формируются локальной языковой моделью или шаблонами; они могут содержать ошибки и должны проверяться слово за словом до подписания.
- Программа не сертифицирована как медицинское изделие Министерством здравоохранения Республики Узбекистан или иным регулирующим органом.

## Сводка по точности (только валидированный детектор)

| Детектор | Статус | Показатель | Значение |
|---|---|---|---|
| Триаж исследования — норма / патология (локальный) | валидировано | Чувствительность на уровне исследования | **0,90** (отмечено 118 из 131 патологического исследования) |
| | | Специфичность на уровне исследования | **0,47** (не отмечено 22 из 47 нормальных исследований) |
| | | Точность (accuracy) | 0,79 |

**Как измерялось.** Модель триажа (классификатор изображений ViT-B) дообучена на МРТ-исследованиях головного мозга ташкентской клиники с метками уровня исследования, полученными из заключений самой клиники, и проверена на **178 отложенных пациентах** (131 с патологией, 47 без), не участвовавших в обучении — 890 аксиальных срезов, по 5 центральных срезов на исследование. Для каждого исследования вероятности патологии по 5 срезам усредняются, и исследование отмечается при среднем ≥ 0,50 — тот же протокол, что выполняется в эксплуатации. Скрипт оценки: `scripts/eval_study_level.py`, результаты в `models/brain_triage_finetuned/study_level_eval.json` (оценка от 2026-09-07). Тот же скрипт блокирует выпуск модели, если чувствительность падает ниже 0,85 или специфичность ниже 0,40. Обратите внимание на малое число нормальных исследований (47): оценка специфичности неточна (95 % ДИ примерно 0,33–0,61). Метки получены из заключений и применены на уровне исследования, а не по экспертной разметке каждого среза. Для подтверждения этих показателей в каждой клинике требуется тестовый набор, размеченный рентгенологами в ходе пилота (см. `pilot_evaluation_protocol_ru.md`).

Для классификатора опухолей, для КТ и для качества текста заключений показатели точности не заявляются.

## Заявление об ответственности

Sentinel Medical AI обеспечивает только поддержку принятия решений. **Квалифицированный врач-рентгенолог полностью читает каждое исследование и подписывает каждое заключение; подписанное заключение — профессиональное действие и ответственность врача.** Вывод ИИ никогда не должен быть единственным основанием клинического решения. Врачей просят сообщать о каждом предполагаемом ложном или пропущенном флаге ИИ руководителю пилота в клинике, чтобы модели можно было валидировать и улучшать.

## Идентификация версии и моделей

| Элемент | Идентификатор |
|---|---|
| Настольное приложение / сервер ИИ | 1.0.0 (на экране входа, в строке состояния, в `/health` и в каждом PDF) |
| Валидированная модель триажа | `models/brain_triage_finetuned` — SHA-256 файла `model.safetensors` `0d559766ce58…` (зафиксирован в `MANIFEST.json`; первые 12 символов показываются в приложении и печатаются в заключениях) |
| Классификатор опухолей мозга (валидация не завершена) | публичный пакет модели Hugging Face; идентификатор (название + отпечаток SHA-256 + статус) показывается с каждым результатом |
| Порог принятия решения | 0,50 (печатается в каждом заключении) |
| Языковая модель для текста заключений | Gemma 3 через Ollama, локально; резервный вариант — шаблоны |

Каждый результат и каждый PDF несут идентификаторы и статус валидации создавших их моделей, поэтому любое заключение можно соотнести с конкретным выпуском модели.
